# Printable files

Four parts, in STL for printing and STEP for editing. All are in true millimetres and need no scaling.

| File | Qty per unit | Bed orientation |
|---|---|---|
| `VolAnti_Base` | 1 | As exported |
| `VolAnti_Lid` | 1 | Top face down |
| `VolAnti_GrilleRing` | 4 | Flat side down, 0.1 mm layers |
| `VolAnti_Mount` | 1 | As exported |

Print settings, fit checks and the rules for remixing are in [../README.md](../README.md).
