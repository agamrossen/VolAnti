# Gerbers

Fabrication outputs for PCB **rev A2**: the Gerber set and the Excellon drill file, zipped in the form JLCPCB and PCBWay both accept.

`VolAnti_revA2_gerbers.zip`

## Board parameters

| | |
|---|---|
| Size | 84 × 84 mm |
| Layers | 4 |
| Thickness | 1.6 mm |
| Surface finish | ENIG |
| Copper weight | 1 oz outer |
| Minimum track and gap | as generated, comfortably inside standard capability |

Upload the zip as-is. It does not need unpacking, and the layer names are the fab's default convention.

For assembly, upload [../bom.csv](../bom.csv) and [../pick-and-place.csv](../pick-and-place.csv) alongside it. The click-by-click walkthrough is in [../README.md](../README.md).
